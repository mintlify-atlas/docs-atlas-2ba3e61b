---

BepInEx is the go-to plugin framework for modding Unity and .NET games. It injects into any supported game at startup — no patching required — and provides a complete toolkit for plugin authors: dependency management, configuration, logging, and assembly patching.

## Platform support

| Runtime | Windows | macOS | Linux |
|---|---|---|---|
| Unity Mono | Yes | Yes | Yes |
| Unity IL2CPP | Yes | No | Yes |
| .NET / XNA | Yes | Mono | Mono |

<Steps>
  <Step title="Download BepInEx">
    Grab the latest release for your platform from [GitHub Releases](https://github.com/BepInEx/BepInEx/releases).
  </Step>
  <Step title="Extract into your game folder">
    Unzip BepInEx so the `BepInEx/` folder and `winhttp.dll` (or equivalent) sit next to your game executable.
  </Step>
  <Step title="Run the game once">
    Launch the game to let BepInEx complete its first-run setup and generate the configuration file.
  </Step>
  <Step title="Install or write plugins">
    Drop plugin DLLs into `BepInEx/plugins/` or follow the [plugin quickstart](/dev-guide/plugin-quickstart) to write your own.
  </Step>
</Steps>
